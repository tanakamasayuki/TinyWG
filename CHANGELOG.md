# Changelog / 変更履歴

## Unreleased
- (EN) First implementation: WireGuard protocol engine (initiator and responder, multiple peers), lwIP netif adapter (TinyWG), Arduino UDP adapter (TinyWGUdp).
- (JA) 初期実装: WireGuard プロトコルエンジン(イニシエータ / レスポンダ、複数ピア)、lwIP netif アダプタ(TinyWG)、Arduino UDP アダプタ(TinyWGUdp)。
- (EN) Beginner's and advanced guides (docs/), in English and Japanese.
- (JA) 初心者ガイドと上級者ガイド(docs/、日英)。
- (EN) SPEC.md in English; a README for each example.
- (JA) 英語版の SPEC.md、サンプルごとの README。
- (EN) API reference (docs/api.md), in English and Japanese.
- (JA) API リファレンス(docs/api.ja.md、日英)。
- (EN) setTimestampReset(): a responder can accept clients whose clock went back after a reboot.
- (JA) setTimestampReset(): 再起動で時計が戻ったクライアントをレスポンダが受け付けられる。
- (EN) TinyWGTimeServer: an optional simple NTP server, so clients can take the time from the WireGuard server. Esp32Server uses it.
- (JA) TinyWGTimeServer: WireGuard サーバーから時刻を配れる、必要なら使う簡易 NTP サーバー。Esp32Server で使用。
- (EN) TinyWG::setOuterUdp(): the outer UDP over any Arduino UDP (a W5500 on the Ethernet library, a modem's AT socket) while wg0 stays in lwIP. The library drives it (a task on ESP32, lwIP's timer on CH32V), or update() does.
- (JA) TinyWG::setOuterUdp(): wg0 は lwIP のまま、外側の UDP を任意の Arduino UDP(W5500 の Ethernet ライブラリ、モデムの AT ソケット)にする。ライブラリが自分で回す(ESP32 はタスク、CH32V は lwIP のタイマー)か、update() で回す。
- (EN) About 1.6 KB less RAM: the lwIP adapter's scratch buffer and the per-peer derived keys are gone. Device::innerBuffer() lets a caller write a packet where it is encrypted.
- (JA) RAM を約 1.6 KB 削減: lwIP アダプタの作業バッファとピアごとの派生鍵をなくした。Device::innerBuffer() で、暗号化する場所に直接パケットを書ける。
- (EN) The packet waiting for a handshake waits in the send buffer (about 1.3 KB less RAM); setStagingBuffer() gives it a buffer of its own for gateways with several peers. TINYWG_STAGED_PACKET is gone.
- (JA) ハンドシェイク待ちのパケットを送信バッファの中で待たせる(RAM 約 1.3 KB 減)。複数ピアのゲートウェイは setStagingBuffer() で専用の領域を渡せる。TINYWG_STAGED_PACKET は廃止。
- (EN) tinywg::CookieGuard: cookie replies under load (whitepaper §5.4.7) for servers facing handshake floods, attached with setCookieGuard(); not linked unless used. Stats gain cookiesSent and rxUnderLoad.
- (JA) tinywg::CookieGuard: ハンドシェイクの洪水に対し、負荷が高いときに Cookie Reply で応じる(ホワイトペーパー §5.4.7)。setCookieGuard() で付け、使わなければリンクされない。Stats に cookiesSent と rxUnderLoad を追加。
- (EN) The lwIP adapter hands a received pbuf with memory of its own (CH32V Ethernet, arduino-pico, setOuterUdp()) on to lwIP as the inner packet, with no copy.
- (JA) lwIP アダプタは、自分のメモリを持つ受信 pbuf(CH32V の Ethernet、arduino-pico、setOuterUdp())を、コピーせずに内側のパケットとして lwIP に渡す。
- (EN) beginConfig(): begin() and the peers from wg-quick text, for TinyWG and TinyWGUdp; not linked unless called.
- (JA) beginConfig(): wg-quick 形式のテキストから begin() とピアの登録まで行う(TinyWG と TinyWGUdp)。呼ばなければリンクされない。
- (EN) arduino-pico in FreeRTOS mode: TinyWGUdp, Device and TinyWGTimeServer build; only TinyWG (lwIP) is disabled, with a static_assert saying so when used.
- (JA) arduino-pico の FreeRTOS モード: TinyWGUdp、Device、TinyWGTimeServer はビルドできる。TinyWG(lwIP)だけを無効にし、使うと static_assert でその旨を出す。
- (EN) Esp32W5500Client example: a W5500 on Arduino's Ethernet library as the outer side.
- (JA) Esp32W5500Client サンプル: Arduino の Ethernet ライブラリで動かす W5500 を外側に使う。
- (EN) Tests: board_responder and board_pair run with each outer mode; board_pair over the full product of boards (--profiles=all --peer-profiles=all).
- (JA) テスト: board_responder と board_pair を外側の各モードで実行。board_pair はボードの全組合せ(--profiles=all --peer-profiles=all)。
